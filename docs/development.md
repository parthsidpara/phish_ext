# Development Guide

## Prerequisites

- Node.js >= 22.6 (`scripts/hash-png.ts` relies on `node --experimental-strip-types`)
- pnpm >= 9
- Python 3 + Playwright (only for the dataset tooling — see `tools/README.md`)

## Setup

```bash
git clone https://github.com/parthsidpara/phish_ext.git
cd phish_ext
pnpm install   # install deps + run wxt prepare (postinstall)
pnpm dev       # start dev mode, opens Chromium with extension loaded
```


## How the pipeline works

1. **Page loaded** — `background.ts` detects navigation via `webNavigation.onCompleted`.
2. **Screenshot** — background calls `tabs.captureVisibleTab` and sends the image to the offscreen document.
3. **pHash** — offscreen document decodes the image and runs the DCT-based perceptual hash (Layer 1).
4. **Visual match** — background compares the hash against each brand's reference hashes
   (primary + `phashByViewport`, picking the closest) within the brand's threshold.
5. **Domain check** — Layer 2. If a visual match is found, background runs
   `checkDomainLegitimacy()`: allowlist (exact or subdomain) → safe; homoglyph /
   Levenshtein lookalike → typosquatting; otherwise → domain mismatch.
6. **Aggregation** — background builds a `DetectionResult{ riskScore, matchedBrand, flaggedElements, reasoning }`.
   Layer 3 (DOM features, logo matching) is not yet wired into the verdict — see status below.
7. **Warning** — background sends `DETECTED` to the content script, which dispatches to the
   active warning condition (banner / modal / tooltip / icon / progressive) and logs every user action.

## Warning conditions

The popup selects the active condition (stored under `phish_condition`):

| Condition | Behavior |
|---|---|
| Banner | Dismissible strip at the top of the page, non-blocking. |
| Modal | Full-screen interceptor, forces an explicit choice. |
| Tooltip | Warning anchored to the password field. |
| Passive icon | Corner indicator; click to expand the reasoning. |
| Progressive Reveal | Adaptive: passive icon → highlight/banner → modal, escalating as the user hesitates (dwell, cursor proximity to the password field, focus/typing). |

Driver.js (`highlightFlaggedElements`) runs alongside banner/icon and shows the evidence tour
once `flaggedElements` carry CSS selectors (from Layer 3 / visual-similarity flags).

## Building for production

```bash
pnpm build              # Chrome/Chromium
pnpm build:firefox      # Firefox
pnpm zip                # Creates .zip for store submission
```

## Testing in Firefox

```bash
pnpm dev:firefox
```

Note: Layer 1 (and therefore detection) is skipped in Firefox — the `offscreen` API is
Chromium-only. Development currently targets Chromium.
